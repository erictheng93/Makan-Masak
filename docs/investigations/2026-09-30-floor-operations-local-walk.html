本機環境的雜訊，不是產品問題：三個 wrangler dev（api、realtime、management-api）共用一份 SQLite， 偶發 database is locked: SQLITE_BUSY，表現為 realtime 第一次 WebSocket 連線 403（隨即重連成功）與一次 /pos/reports/daily 回 400。NODE_ENV=test 下，讀 user 失敗的 auth 會被當成「使用者不存在」回 401； production 分支會直接丟出錯誤而不是 401（middleware/auth.ts 的 loadTokenUser）。 chef1／cashier1 的種子密碼不明，本機把它們的雜湊改成 owner1 的，並清掉登入限流的 KV。
