# Issue 431 and multiple coupons implementation plan

> **For agentic workers:** Use subagent-driven-development or executing-plans to implement the assigned task. Preserve other workers' edits.

**Goal:** Repair POS data contracts and support merchant-controlled, limited, mutually exclusive coupons selected by customers and visible at checkout.

**Architecture:** Reuse CouponService for validation and authoritative consumption, OrderService for money calculation and persisted discount snapshots, and the existing coupon editor. Existing single-code clients remain supported. No new dependencies.

**Tech Stack:** Vue 3, TypeScript, Hono, Drizzle, Cloudflare D1, pnpm, Vitest.

**Spec:** User-approved requirements recorded below.

## Spec and global constraints

- Merchants configure coupon expiry, quantity, and incompatible coupon IDs.
- Customers select multiple electronically issued coupons or enter codes; choices are submitted with the order.
- Apply percentages sequentially, then fixed discounts, preserving selection order within each kind. Either direction of incompatibility rejects a pair. Cap total discount at merchandise subtotal.
- Validate eligibility against original merchandise subtotal. Revalidate on order submission; client totals are never authoritative.
- Persist each coupon's code, name, and discount so POS shows the actual charged details.
- Preserve existing tenant, currency, per-customer, guest, expiry, cancellation, and usage-limit safeguards.
- pnpm only; current workspace; local atomic commits after verification; no push or PR.

## Review focus

- Concurrent claims for the last available coupon cannot oversubscribe; a later failed claim releases earlier claims.
- Duplicate codes cannot apply twice; either-direction incompatibility fails.
- Coupon expiry or deletion after preview is rejected on submission.
- Zero remaining merchandise value, capped percentages, and currency rounding never yield negative totals.
- Order mutations, cancellation, and historical display preserve accurate coupon accounting.
