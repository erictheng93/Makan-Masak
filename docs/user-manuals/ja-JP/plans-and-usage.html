まずは要点

  • MakanMasak のプランはトライアル、スタンダード、プロフェッショナル、エンタープライズの4種類です。新しい店舗はすべてトライアルから始まり、180 日間、すべての機能をお使いいただけます。
  • トライアルが終わっても、停止されることはありません。プランの選択をお願いする案内が表示されるだけで、お店は通常どおり営業できます。
  • 各プランには注文数・印刷数などの使用量の上限があります。80% に達するとお知らせし、上限に達すると、次の集計期間になるか、プランをアップグレードするまで、新規の注文とレシート印刷が一時停止されます。
  • プランは店主ご自身が管理画面の プランと使用量 から変更できます。オンライン決済は不要で、サポートへの連絡も要りません。
  • アップグレードはすぐに反映され、使用量は 0 から数え直されます。ダウングレードは今期の終了時に反映され、反映前なら取り消せます。
  • このページでは料金には触れていません。今後料金が発生する場合は、プラットフォームから別途お知らせします。

無料トライアル

  • 新しい店舗はすべてトライアルから始まり、180 日間、すべての機能をお使いいただけます。
  • プランと使用量 のページでは、現在のプランの下に「試用期間はあと N 日です」と表示されます。
  • トライアルの注文数と印刷数の上限はトライアル期間全体の合計（それぞれ 3,000）で、毎月リセットされるものではありません。

トライアル終了後

何も停止されません すべての機能をこれまでどおりお使いいただけますので、お店を休む必要はありません。管理画面にお知らせが表示されるだけです。画面の上部に「無料トライアルは終了しました。引き続きすべての機能をご利用いただけますが、MakanMasak を支援するためプランをご選択ください。」というバナーが出ます。また、ログインのたびに一度「無料トライアルは終了しました」というダイアログが表示されます。「続ける」を押して閉じるか、「プランを選ぶ」を押してそのままプランの選択に進めます。
  • トライアル終了後、プランを選ぶまでの間は、使用量の上限はトライアルの数字のままですが、暦月ごとの集計になります（毎月 0 に戻ります）。
  • トライアルから移る（スタンダード、プロフェッショナル、エンタープライズを選ぶ）場合は、すぐに反映されます。
  • トライアルを離れると、トライアルには戻れません。トライアルは新しく開いた店舗のみが対象です。

使用量の数え方と確認できる場所

システムは、上限のある次の3種類の使用量を数えます。

  • 注文の作成：新しい注文を1件作成するごとに 1 と数えます。お客様がオンラインや QR コードから入れた注文、グループ注文、複数店舗にまたがる合算会計、スタッフが代理で作成した注文が含まれます。
  • 印刷ジョブ：レシートを1回印刷するごとに 1 と数えます。
  • AI リクエスト：AI分析 の機能を使ったときに数えます。

「1期間」とはどのくらいか

店舗の状況使用量の数え方
トライアル期間中トライアル期間全体（180 日間）の合計で、リセットされません
トライアル終了後、プラン未選択暦月ごとに集計し、月初に 0 に戻ります
スタンダード、プロフェッショナル、エンタープライズそのプランを選んだ時点から 30 日ごとが1期間です。期間が終わると自動的に次の期間に入り、0 から数え直します

暦月の区切りは協定世界時（UTC）が基準で、現地時間とは時差があります。たとえば日本では、毎月 1 日の午前 9 時に 0 に戻ります。

確認できる場所

  1. 管理画面にログインし、左側のメニューから プランと使用量 を選びます。
  2. 「今期の使用量」の欄に、項目ごとの使用済みの数と上限、そしてこの期間の開始日と終了日が表示されます。
  3. 進捗バーは使用量に応じて色が変わります。80% 未満は青、80% に達するとオレンジ、上限に達すると赤です。

上限が近づいたときのお知らせ

使用量が上限の 80% に達すると、管理画面の上部にオレンジ色のバナーが表示されます。たとえば「今期の注文数が上限の 85% に達しました（2,550/3,000）」のように表示され、横に プランを見る ボタンがあります。右側の ✕ を押すと閉じられます（今回のログイン中は再表示されません）。このお知らせは店主様にのみ表示されます。

使用量が上限に達したとき

使用量が上限に達すると、次の集計期間が始まるかプランをアップグレードするまでの間、次のようになります。

  • 新規の注文は受け付けられません：お客様はオンラインや QR コードから注文できず、スタッフも代理での新規注文やグループ注文の開始ができません。すでに成立している注文には影響しません。調理、提供、会計はこれまでどおり行えます。
  • レシートを印刷できません。
  • そのほかの機能には影響しません。

このとき、管理画面の上部に閉じることのできない赤いバナーが表示されます：「注文数の上限に達しました。現在お客様は注文できません」または「印刷数の上限に達しました。現在レシートや伝票を印刷できません」。システムから通知メールも届きます（「通知メール」をご覧ください）。

最も早く復旧する方法：プランのアップグレード アップグレードはすぐに反映され、使用量も 0 から数え直されます。上限に達したばかりのお店でも、アップグレード後すぐにまた注文を受けられます。手順は次の節をご覧ください。

お客様の画面には「現在は注文できません」としか表示されません。お客様から指摘されて気づくことがないよう、使用量が上限に近づいた段階（オレンジ色のバナーが出た時点）で対応しておくことをおすすめします。

プランのアップグレード（すぐに反映）

アップグレードとは、下位のプランから上位のプランへの変更のことです：スタンダード → プロフェッショナル → エンタープライズ。トライアルからどの有料プランに移る場合も、すぐに反映されます。トライアルより機能が少ないプラン（たとえばスタンダード）に移る場合は、カードのボタンが 今すぐ変更、確認ダイアログのボタンが 変更を確定 になります。

  1. 管理画面にログインし、左側のメニューから プランと使用量 を選びます。（使用量のお知らせバナーの プランを見る や、トライアル終了のバナーの プランを選ぶ からも、次の手順の画面に直接移動できます。）
  2. 下へ進み、「プランを選ぶ」の欄を探します。4種類のプランがそれぞれカードになっており、期間あたりの上限と含まれる機能が書かれています。現在のプランには「現在のプラン」と表示されています。
  3. 希望のプランのカードで 今すぐアップグレード を押します。
  4. 確認ダイアログ「○○に変更」が表示され、「すぐに反映されます。」と「今期の利用量は 0 から再計算されます。」の文言、そして「利用できるようになる機能」が一覧で示されます。内容を確認して アップグレードを確定 を押します。
  5. 「プランを○○に変更しました」と表示されれば完了です。上部のオレンジ色や赤色のバナーは、まもなく消えます。
アップグレード後 新しい機能がすぐに使えるようになります。使用量は 0 に戻り、新しい 30 日間の集計期間がこの時点から始まります。以前にダウングレードを予約していた場合は、それも取り消されます。支払いも、どなたかへの連絡も必要ありません。

プランのダウングレードと取り消し

ダウングレードとは、上位のプランから下位のプランへの変更のことで、たとえばプロフェッショナル → スタンダードです。ダウングレードはすぐには反映されず、今期の終了を待って切り替わります。それまでは、現在のプランのすべての機能を引き続きお使いいただけます。

ダウングレードを予約する

  1. プランと使用量 の「プランを選ぶ」の欄で、変更したい下位のプランを探します。
  2. カードの ダウングレードを予約（○月○日 に反映） を押します（日付は今期の終了日です）。
  3. 確認ダイアログには「今期の終了時（日付）に反映されます。それまでは現在のプランの機能を利用できます。」と「新しいプランの利用量は、反映日から改めて計算されます。」が表示され、「利用できなくなる機能」と「変更後の影響」が一覧で示されます。たとえば「今後の予約 3 件は保持され、お客様は引き続き確認・キャンセルできますが、管理画面では管理も新規受付もできなくなります。アップグレードすると元に戻ります」のように表示されますので、1つずつご確認ください。
  4. 変更してよければ ダウングレードの予約を確定 を押します。「○○へのダウングレードを予約しました」と表示されます。

予約すると、ページの上部にオレンジ色の案内「○月○日 に ○○ へダウングレードする予約があります」が表示され、プランのカードにも「○月○日 に反映予定」と表示されます。別のダウングレードをさらに予約した場合は、前の予約が置き換えられます。

反映のタイミング

今期の終了時に、システムが自動的に新しいプランへ切り替え、新しい期間を開始して使用量を 0 から数え始めます。システムは予約された変更を1日に1回処理するため、実際の切り替えは画面上の日付より数時間遅れることがあります。それまでは元のプランのままです。

予約したダウングレードを取り消す

  1. プランと使用量 ページの上部にあるオレンジ色の案内で、ダウングレードを取り消す を押します（予約中のプランのカードのボタンも、同じ表示に変わります）。
  2. 「予約したダウングレードを取り消しますか？」のダイアログで確認します。現在のプランのまま利用を続けられます。「ダウングレードを取り消しました」と表示されれば完了です。

反映された後は取り消せません。元のプランに戻したいときは、「アップグレード」の手順でもう一度アップグレードしてください。

機能が使えなくなった場合はどうなるか

ダウングレード（またはトライアルから機能の少ないプランへの変更）をすると、新しいプランに含まれない機能は次のように扱われます。

  • 管理画面の対応する画面が閉じられます。たとえばスタンダードに下げると、POS レジ、キッチンディスプレイ、クーポン、予約、分析の画面には入れなくなります。
  • データは削除されません。予約、サービス予約、シフト表、食材、クーポンなどの記録はそのまま残り、一時的に見られなくなるだけです。あとでそれらの機能があるプランに戻せば、すべて元に戻ります。
  • お客様側：
    • お客様は、オンライン予約やサービス予約の新規追加ができなくなり、順番待ちへの登録もできません。順番待ちのリアルタイムの待ち状況も提供されなくなります。
    • お客様は、すでにある予約、サービス予約、順番待ちを引き続き確認し、取り消すことができます。
    • 店舗独自のクーポンは使えなくなります。プラットフォームが発行したクーポンには影響しません。
  • デリバリープラットフォーム連携：デリバリープラットフォームからの注文は引き続き届き、管理画面から連携を切断することも引き続き可能です。ただし、連携の設定や同期はできなくなり、関連する設定と一覧の画面は閉じられます。
  • スタッフ管理：予定済みのシフトと承認待ちの休暇申請は保持されますが、シフト画面と休暇画面は閉じます。在庫管理：注文に応じた在庫の引き落としは自動で続きますが、確認や管理はできなくなります。アップグレードすると元に戻ります。

ダウングレードの前に、確認ダイアログが店舗の実際のデータに基づいて影響を受ける件数をお知らせします。「ダウングレードの予約を確定」を押す前によくご確認ください。

特別なケース

終了していないレジ締め前のシフトがある

POS のあるプランから POS のないプランへ変更する場合（プロフェッショナルまたはエンタープライズ → スタンダード、あるいはトライアル → スタンダード）は、先にレジのシフトを終了する必要があります。

  • すぐに反映される場合（トライアルからスタンダード、ボタンは「今すぐ変更」）：シフトが終了していないと、システムは変更を受け付けず、「未終了のレジシフトがあります。ダウングレード前に POS で終了してください。」と表示します。確認ダイアログの POS でシフトを終了する から、そのまま POS へ移動できます。
  • 予約したダウングレード：反映日にシフトがまだ開いている場合、ダウングレードはシフトが終了してから反映されます。ページには「○○へのダウングレードは予約済みですが、未終了のレジ締め前シフトがあるため、シフトを終了するまで反映されません。」と表示されます。できるだけ早くシフトを終了してください。
プランが「選択できません」と表示される：そのプランはお住まいの地域で提供されていません

一部のプランは国や地域によってまだ提供されておらず、カードに「このプランはお住まいの地域ではまだ提供されていません。」と表示され、ボタンも押せません。ほかのプランをお選びください。

トライアルが「選択できません」と表示される

トライアルを離れると戻ることはできません。カードには「トライアルは新規店舗のみで、再度利用することはできません。」と表示されます。

「プランがたった今ほかの人によって変更されました」

別の店主アカウントやプラットフォームの担当者が、操作と同じタイミングでプランを変更した場合、「プランがたった今ほかの人によって変更されました。画面を更新しましたので、内容を確認してからもう一度お試しください。」と表示されます。操作は実行されていません。画面は最新の状態に更新されていますので、内容を確認してもう一度操作してください。

「すでにこのプランをご利用中です。」または「予約中のダウングレードはもうありません。画面を更新しました。」

画面の情報が古くなっていることを示しています（たとえば別のタブですでに操作した場合など）。システムが自動的に画面を更新しますので、何もする必要はありません。

「サブスクリプションが無効のため、プランを変更できません。サポートにお問い合わせください。」

プラットフォーム側でサブスクリプションが無効にされている間は、ご自身でプランを変更できません。「フィードバック」ページからご連絡いただければ、プラットフォームの担当者が対応します。

届く通知メール

次のような場合、システムは店舗に登録された連絡先のメールアドレスにメールを送ります（普段確認されるメールアドレスであることをご確認ください）。

  • プランの変更：アップグレードがすぐに反映されたとき、または予約したダウングレードが期日を迎えて反映されたとき。
  • ダウングレードの予約：メールには反映される日付と、管理画面で取り消せることが書かれています。
  • ダウングレードの取り消し。
  • 使用量の上限到達：同じ項目の使用量については、同じ期間に1回だけ送信されます。

現在、これらの通知メールはすべて英語で送信されます。

プランを変更できる人

店主（とプラットフォームの担当者）だけが、プランと使用量 を表示してプランを変更できます。シェフ、サービススタッフ、レジ担当などほかのスタッフのアカウントにはこのページが表示されず、変更もできません。使用量のお知らせバナーも店主様にのみ表示されます。

よくある質問

トライアルが終了しました。お店は停止されますか？

いいえ。トライアル終了後も、すべての機能を引き続きお使いいただけます。管理画面でプランの選択をお願いする案内が表示されるだけです。ただし、使用量の上限は毎月リセットされる形に変わります（数字はトライアルのままです）。

アップグレードすると、これまでの使用量は 0 に戻りますか？

はい。アップグレードはすぐに反映され、新しい 30 日間の集計期間がアップグレードした時点から始まり、使用量は 0 から数え直されます。そのため、使用量が上限に達して注文を受けられなかったお店でも、アップグレード後すぐにまた注文を受けられます。

ダウングレードすると、データは消えますか？

いいえ。記録はすべて残り、関連する管理画面が一時的に閉じられるだけです。あとでその機能のあるプランにアップグレードすれば、データは元に戻ります。

お客様から注文できないと言われました。なぜですか？

最もよくある原因は、今期の注文数が上限に達していることです。管理画面の プランと使用量 で「今期の使用量」を確認してください。注文数が上限に達している場合は、上部に赤いバナーが表示されます。プランをアップグレードすればすぐに復旧します。アップグレードしない場合は、次の集計期間が始まるまでお待ちください。

トライアルに戻せますか？

いいえ。トライアルを離れると、トライアルには戻れません。トライアルは新しく開いた店舗のみが対象です。

ダウングレードをすぐに反映できますか？

いいえ。ダウングレードは必ず今期の終了時に反映され、反映前なら取り消せます。

プランの変更には料金がかかりますか？

現在、管理画面でのプラン変更にオンライン決済は不要です。今後料金が発生する場合は、プラットフォームから別途お知らせします。

使用量が上限に達しましたが、アップグレードしたくない場合は？

次の集計期間が始まるまでお待ちいただけます（トライアル終了後は翌月 1 日、有料プランは現在の期間の終了日で、日付は「今期の使用量」の右上に表示されます）。それまでの間、新規の注文とレシート印刷は一時停止されます。
