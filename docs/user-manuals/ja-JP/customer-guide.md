## 🎉 MakanMakanへようこそ

MakanMakanは、スマートフォンでメニューの閲覧、注文、リアルタイムでの注文状況確認ができる、モダンなスマートオーダリングプラットフォームです。アプリのダウンロードは不要 - QRコードをスキャンするだけで始められます！

### ✨ 主な特徴

- 📱 **アプリ不要** - モバイルブラウザから直接利用可能
- 🎯 **シンプル & 高速** - QRコードをスキャンして注文
- 📊 **リアルタイム追跡** - いつでも注文状況を確認
- 💾 **オフライン対応** - ネット環境が不安定でも動作
- 👤 **会員システム** - 登録後、注文履歴の確認が可能
- 🌐 **多言語対応** - 繁体字中国語、英語、ベトナム語、インドネシア語、フィリピン語、日本語

## 🍽️ 注文方法

MakanMakanは、レストランの設定に応じて2つの注文方法を提供しています：

### 方法1：テーブルQRコード注文

**利用シーン**: 固定席のある店内飲食レストラン

#### 📍 使い方

1. **テーブルのQRコードを探す**
   - 通常、テーブル、テーブルスタンド、または食器に配置
   - 各テーブルには固有のQRコードがあります

2. **QRコードをスキャン**

   ```
   方法1: スマホのカメラアプリを使用
   └─ カメラを開いてQRコードに向ける
   └─ 表示されたリンク通知をタップ

   方法2: LINE/WeChatのスキャナーを使用
   └─ スキャン機能を開く
   └─ QRコードに向ける
   ```

3. **注文を開始**
   - スキャン後、メニューページが自動的に開きます
   - ご注文はこのテーブルに紐付けられます
   - 登録不要で注文可能

#### 🎯 特徴

- ✅ 登録なしで直接注文
- ✅ 注文が自動的にキッチンに送信
- ✅ スタッフがテーブル番号を確認可能
- ✅ 追加注文可能（再度スキャン）

---

### 方法2：店舗QRコード注文

**利用シーン**: テイクアウトカウンター、屋台、ポップアップストア、フードトラック

#### 📍 使い方

1. **店舗QRコードをスキャン**
   - 通常、カウンターまたは店頭に配置
   - 店舗全体で1つのQRコード

2. **電話番号確認が必要（初回のみ）**

   **ステップ1: 電話番号を入力**

   ```
   ┌──────────────────────────┐
   │  電話番号を入力          │
   │  ┌────────────────────┐  │
   │  │ +81 90-1234-5678   │  │
   │  └────────────────────┘  │
   │                          │
   │  [確認]                  │
   └──────────────────────────┘
   ```

   - 国番号付きで電話番号を入力
   - 例：日本 +81、マレーシア +60

   **ステップ2: 認証コードを入力（オプション）**
   - 一部のレストランでは電話確認が必要
   - SMSで6桁のコードを受信
   - コードを入力して認証を完了

3. **注文を開始**
   - 認証後、メニューを閲覧
   - カートに追加して注文を送信

4. **商品の受け取り**
   - 注文には電話番号の下4桁が表示されます
   - スタッフが番号で呼び出します
   - 例：「5678番のお客様、ご注文の品ができました！」

#### 🎯 特徴

- ✅ テイクアウトに最適
- ✅ 電話番号が受取番号に
- ✅ 注文状況の確認可能
- ✅ 事前注文対応

#### 📝 登録手順

   - ホームページの「登録」をクリック

2. **登録フォームに記入**

   ```
   ┌────────────────────────────────┐
   │  会員登録                      │
   │                                │
   │  氏名                          │
   │  ┌──────────────────────────┐  │
   │  │ 山田 太郎                 │  │
   │  └──────────────────────────┘  │
   │                                │
   │  電話番号                      │
   │  ┌──────────────────────────┐  │
   │  │ +81 90-1234-5678         │  │
   │  └──────────────────────────┘  │
   │                                │
   │  メール（任意）                │
   │  ┌──────────────────────────┐  │
   │  │ yamada@example.com       │  │
   │  └──────────────────────────┘  │
   │                                │
   │  パスワード                    │
   │  ┌──────────────────────────┐  │
   │  │ ••••••••                 │  │
   │  └──────────────────────────┘  │
   │                                │
   │  パスワード確認                │

   │  │ ••••••••                 │  │
   │  └──────────────────────────┘  │
   │                                │
   │  [登録]                        │
   └────────────────────────────────┘
   ```

3. **登録完了**
   - 「登録」ボタンをクリック
   - システムが自動的にログイン

#### ⚠️ 重要事項

- 電話番号は必須（ログインIDとして使用）
- パスワードは8文字以上
- メールは任意（パスワードリセット用）

#### 🔐 ログイン手順

1. **ログインページへ移動**
   - ホームページの「ログイン」をクリック

2. **認証情報を入力**

   ```
   ┌────────────────────────────────┐
   │  会員ログイン                  │
   │                                │
   │  電話番号                      │
   │  ┌──────────────────────────┐  │

   │  └──────────────────────────┘  │
   │                                │
   │  [ログイン]                    │
   │                                │
   │  パスワードを忘れた? | 登録    │
   └────────────────────────────────┘
   ```

3. **ログイン成功**
   - 注文ページへ自動移動
   - または前のページに戻る

#### 💡 ヒント

- ログイン状態を保持すると注文追跡が簡単
- パスワードを忘れた場合は「パスワードを忘れた？」をクリックしてリセット

### 注文履歴

会員はすべての過去の注文を確認できます。

#### 📜 確認方法

1. 会員アカウントにログイン
2. 「プロフィール」へ移動
3. 「注文履歴」をクリック

#### 📊 注文情報

各注文には以下が表示されます：

```
┌────────────────────────────────────┐
│  注文 #12345                       │
│  ────────────────────────────      │
│                                    │
│  📅 2025-10-26 14:30              │
│  🏪 美味しいレストラン             │
│  🪑 テーブル: A12                  │
│  💰 合計: ¥3,500                   │
│  📌 ステータス: 完了               │
│                                    │
│  注文内容:                         │
│  • ラーメン x 1  ¥1,500           │
│  • 餃子 x 2  ¥1,000               │
│  • ビール x 2  ¥1,000             │
│                                    │
│  [詳細を見る]                      │
└────────────────────────────────────┘
```

#### 🔍 注文ステータスの説明

| ステータス    | 説明                     |
| ------------- | ------------------------ |
| 🟡 確認待ち   | 注文送信済み、確認待ち   |
| 🔵 調理中     | レストランが受付、調理中 |
| 🟢 完了       | 注文完了                 |
| 🔴 キャンセル | 注文キャンセル           |

   │                                │
   │  💬 備考:                      │
   │  ┌──────────────────────────┐  │
   │  │ ネギ抜きでお願いします   │  │

   - 食材の選択

   - 削除を確認

2. **注文メモを追加**（任意）
   - 例：「お早めに」「別包装」

3. **「注文する」をクリック**
   - システムが注文情報を確認

4. **送信を確認**

   ```
   ┌────────────────────────────────┐
   │  ⚠️ 注文を確定しますか？       │

   └────────────────────────────────┘
   ```

5. **注文送信完了**
   - 注文番号が表示されます
   - 自動的に追跡ページへ移動

#### ⚠️ 重要な注意事項

- ⚠️ 送信後の変更・キャンセル不可
- ⚠️ 送信前に内容をご確認ください
- ⚠️ エラーがある場合はスタッフにお知らせください

## 🪑 順番待ち

店舗が順番待ちを受け付けている場合は、先に整理券を取得でき、店頭で並ぶ必要はありません。順番待ちのURLは、通常、店舗のQRまたはリンクで案内されます（`/r/店舗コード/wait-list`）。

### 整理券を取る

1. 順番待ちページを開きます。タイトルは「順番待ちに登録」です。
2. **お名前**、**携帯電話番号**、**ご利用人数**（1～8名）を入力します。特別なご要望があれば**備考**に記入してください。
3. 携帯電話番号は **09 から始まる台湾の携帯電話番号**である必要があります（例：0912 345 678。スペースと「-」は自動的に無視されます）。そうでない場合は「09 から始まる台湾の携帯電話番号を入力してください。」と表示されます。
4. 「並ぶ」を押します。成功すると、そのまま「マイ整理券番号」ページに移動します。
5. ページ下部に「現在の待ち」組数と「予想待ち時間」（分）が表示されるので、整理券を取る前の目安にできます。

> プッシュ通知は現在ご利用いただけません。整理券を取得したら、このページを開いたままにするか、後で携帯電話番号から照会してください。

### 自分の整理券番号を確認する

「マイ整理券番号」ページには、**整理券番号**、**現在のステータス**、**前に並んでいる組数**、**予想待ち時間**、およびお名前と人数が表示されます。

- 整理券が最終ステータスになるまで、ページは自動的に更新されます。ブラウザのタブがバックグラウンドにある間は更新が一時停止するので、タブに戻れば再開します。
- ステータスは次のとおりです：待機中、呼び出し済み、到着確認済み、着席済み、キャンセル済み、期限切れ、不在。
- このページのURLは公開の場に転載しないでください。このURLが、あなたの整理券の証明になります。

### 呼び出し後に使えるボタン

| ボタン                 | 表示されるタイミング                       | 動作                                   |
| ---------------------- | ------------------------------------------ | -------------------------------------- |
| 到着を確認             | ステータスが「呼び出し済み」のとき         | 来店したことを店舗に伝えます           |
| 先に注文する           | 整理券がまだ終了していないとき             | その店舗のメニューへ移動し、先に注文します |
| 順番待ちをキャンセル   | 整理券がまだ終了していないとき             | この整理券を放棄します                 |
| 再度整理券を取る       | 整理券が終了（キャンセル、期限切れなど）後 | 登録ページに戻り、改めて登録します     |
| ホームへ               | 整理券が終了した後                         | MakanMakan のホームに戻ります          |

### 番号を忘れた、または端末を変えた場合

- 登録ページで「**携帯電話番号で整理券を検索**」を押し、元の携帯電話番号を入力すると、現在有効な整理券を呼び出せます。見つからない場合は「この携帯電話番号に有効な順番待ちはありません。」と表示されます。
- 過去の記録を見たい場合は「**履歴を見る**」（`/r/店舗コード/wait-list/history`）を押し、携帯電話番号を入力して「履歴を読み込む」を押し、「整理券を見る」を押すと、その整理券に戻れます。
- システムが携帯電話の認証を求める場合は、ログインページに移動し、**SMS認証コード**で認証します。完了すると自動的に履歴ページに戻ります。これは正常なフローです。

### 順番待ちのよくある質問

- **整理券が取れない**：店舗がまだ順番待ちを受け付けていないか、一時的に登録できない可能性があります。しばらくしてからもう一度お試しいただくか、店頭のスタッフにお問い合わせください。
- **予想待ち時間が変わらない**：これは目安の値です。店舗からの呼び出しを基準にしてください。
- **整理券が期限切れと表示される**：整理券は無効になっています。「再度整理券を取る」を押してください。

## 🛍️ マーケットの複数屋台会計

「マーケット」ページ（`/markets`）でマーケットを選ぶと、**異なる屋台**の料理を1つのマーケットカートに入れて一度に送信し、その後は同じページで追跡できます。

> この機能は、店舗とプラットフォームの双方で有効になっている必要があります。有効でない場合、送信ボタンはグレーになり「未開放」と表示され、「複数屋台会計はまだご利用いただけません。各屋台で個別に注文してください。」と案内されます。その場合は、各屋台で個別に注文してください。

### 複数屋台の注文を送信する

1. マーケットページで、各屋台の料理を「マーケットカート」に追加します。カートには「N 屋台、N 品」と表示されます。
2. 複数屋台会計には**2屋台以上**が必要です。足りない場合は案内が表示されます。
3. 本日営業していない屋台がある場合は、システムがカートから削除して通知します。確認してから送信してください。
4. **携帯電話番号の下3桁**を入力して「送信」を押します。この3桁は、後で注文を呼び出すための証明になりますので、覚えておいてください。
5. 成功すると「N 件の屋台注文を送信しました」と表示され、マーケット注文の追跡ページ（`/markets/マーケットコード/checkout/会計ID`）に移動します。

### マーケット注文の追跡ページ

ページ上部には、マーケット名と全体のステータス（**処理中**または**送信済み**）、屋台数、送信時刻のほか、次の項目が表示されます。

- **小計**、**クーポン割引**（クーポンを使用している場合）、**お支払い額**。
- **屋台の注文**リスト：屋台ごとに1件の注文と注文番号があり、「屋台の注文を見る」を押すと、その屋台の注文追跡に移動できます。
- 各屋台の調理の進捗（確認待ち、確認済み、調理中、受け取り可、完了……）は引き続き各店舗が管理します。**店舗の現場での呼び出しや通知を基準にしてください**。このページに残るのは、マーケット全体の概要だけです。

### クーポンの使用と一括支払い

1. ページに「クーポンコードを入力」と表示されたら、コードを入力して「適用」を押します。取り消す場合は「削除」を押します。
2. クーポンが使えない場合は理由が表示されます：見つからない、このマーケット会計には適用できない、期限切れ、使い切り、最低利用額に未達。支払い済みの注文では、クーポンを変更できません。
3. 「**一括支払い**」を押すと、すべての屋台を一度に精算できます。支払い中は「支払い処理中」と表示され、支払い方法に応じて支払いページに移動します。**支払いが終わったら、このページに戻って**追跡してください。
4. ページには「X / Y 件の屋台の支払いが完了」と表示されます。一部の屋台の支払いだけが完了した場合、全体は「一部支払い完了」となり、「未完了の支払いを再試行」を押せます。支払いに失敗した場合は「再度支払う」を押し、支払い方法を確認してください。
5. 「マーケットの一括支払いはまだご利用いただけません。各屋台で直接お支払いください」と表示された場合は、各屋台の現場でお支払いください。

### 屋台の注文を開けない場合

「屋台の注文を開けません。最近のマーケット注文から入り直してください」と表示された場合は、この端末に、その子注文へのアクセス資格情報が見つからないことを意味します。マーケット注文の追跡ページに戻って入り直すか、注文番号と携帯電話番号の下3桁をスタッフに伝えて確認を依頼してください。自分で注文を重複して送信しないでください。

## ❓ よくある質問

### 🤔 一般的な使用方法

**Q1: アプリのダウンロードは必要ですか？**
A: 不要です！モバイルブラウザでQRコードをスキャンするだけで利用できます。

**Q2: 注文するには登録が必要ですか？**
A: 必須ではありません。テーブル注文は登録なしで可能です。ただし、登録すると注文履歴を確認できます。

**Q3: 認証コードが届きません**
A: 以下を確認してください：

- 電話番号が正しいか
- SMSがスパムでブロックされていないか
- ネット接続が安定しているか
- スタッフにサポートを依頼

**Q4: 2つのテーブルから同時に注文できますか？**
A: 推奨しません。各テーブルには固有のQRコードがあるため、別々にスキャンしてください。

**Q5: 送信後にキャンセルできますか？**
A: システム上でのキャンセルはできません。すぐにスタッフにお知らせください。

---

### 🛒 ショッピングカート

**Q6: カートに時間制限はありますか？**
A: 24時間保存されます。タイムアウト後にクリアされる場合があります。

**Q7: 一部の料理がカートに追加できないのはなぜ？**
A: 以下の理由が考えられます：

- 一時的に売り切れ
- 提供時間外
- システムメンテナンス中

**Q8: 複数のレストランから同時に注文できますか？**
A: できません。1つのカートには1つのレストランの商品のみ入れられます。

---

### 💰 お支払い

**Q9: 支払い方法は？**
A: 現在、現地払いのみです。食事後にカウンターでお支払いください。

**Q10: クレジットカードやモバイル決済は使えますか？**
A: レストランのポリシーによります。スタッフにご確認ください。

---

### 📱 技術関連

**Q11: ページの読み込みが遅いのはなぜ？**
A: 以下の理由が考えられます：

- ネット信号が弱い
- スマホのメモリ不足
- ページを更新してみてください

**Q12: オフラインでも使えますか？**
A: 読み込み済みのメニューは閲覧できますが、注文送信にはインターネット接続が必要です。

**Q13: 対応しているブラウザは？**
A: 推奨：

- Safari（iOS）
- Chrome（Android）
- その他のモダンブラウザ

**Q14: パソコンで使えますか？**
A: 使えますが、モバイル向けに最適化されています。スマホでの利用を推奨します。

---

### 🔐 アカウント

**Q15: パスワードを忘れました**
A: ログインページの「パスワードを忘れた？」をクリックし、登録済みメールでリセットしてください。

**Q16: 電話番号を変更できますか？**
A: 現在サポートしていません。カスタマーサービスにお問い合わせください。

**Q17: アカウントを削除できますか？**
A: カスタマーサービスにアカウント削除を依頼してください。
