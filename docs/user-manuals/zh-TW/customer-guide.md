## 🎉 歡迎使用 MakanMakan

MakanMakan 是一個現代化的智慧點餐平台，讓您可以透過手機輕鬆瀏覽菜單、下單，並即時追蹤訂單狀態。無需下載 APP，只要掃描 QR Code 即可開始使用！

### ✨ 主要特色

- 📱 **無需下載 APP** - 直接使用手機瀏覽器
- 🎯 **簡單快速** - 掃描 QR Code 即可點餐
- 📊 **即時追蹤** - 隨時查看訂單狀態
- 💾 **離線功能** - 即使網路不穩也能正常使用
- 👤 **會員系統** - 註冊後可查看訂單歷史
- 🌐 **多語言支援** - 繁中、英文、越南文、印尼文、菲律賓文

## 🍽️ 點餐方式

MakanMakan 提供兩種點餐方式，根據餐廳的設定而有所不同：

### 方式一：桌台掃碼點餐

**適用場景**：內用餐廳、有固定座位的餐廳

#### 📍 如何使用

1. **找到您的桌台 QR Code**
   - 通常貼在桌面、桌牌或餐具上
   - 每個桌台都有專屬的 QR Code

2. **掃描 QR Code**

   ```
   方法 1: 使用手機相機 APP
   └─ 打開相機對準 QR Code
   └─ 點擊彈出的連結通知

   方法 2: 使用 LINE/微信等掃描功能
   └─ 打開掃描功能
   └─ 對準 QR Code 掃描
   ```

3. **開始點餐**
   - 掃描成功後會自動打開菜單頁面
   - 您的訂單會自動關聯到這個桌台
   - 無需註冊或登入即可點餐

#### 🎯 特點

- ✅ 直接點餐，無需註冊
- ✅ 訂單自動送到廚房
- ✅ 服務人員可以看到您的桌號
- ✅ 可以追加訂單（重新掃描即可）

---

### 方式二：店家掃碼點餐

**適用場景**：外帶櫃台、攤位、快閃店、食物卡車

#### 📍 如何使用

1. **掃描店家 QR Code**
   - 通常放在櫃台或店門口
   - 整間店只有一個 QR Code

2. **首次使用需要驗證手機**

   **步驟 1：輸入手機號碼**

   ```
   ┌──────────────────────────┐
   │  請輸入您的手機號碼      │
   │  ┌────────────────────┐  │
   │  │ +886 912345678     │  │
   │  └────────────────────┘  │
   │                          │
   │  [確認]                  │
   └──────────────────────────┘
   ```

   - 輸入您的手機號碼（含國碼）
   - 例如：台灣 +886，馬來西亞 +60

   **步驟 2：接收驗證碼（可選）**
   - 有些餐廳會啟用手機驗證
   - 您會收到 6 位數驗證碼簡訊
   - 輸入驗證碼完成驗證

3. **開始點餐**
   - 驗證成功後即可瀏覽菜單
   - 加入購物車並送出訂單

4. **取餐**
   - 訂單會顯示您的手機後 4 碼
   - 店家叫號時會叫您的號碼
   - 例如：「5678 號，您的餐點好了！」

#### 🎯 特點

- ✅ 適合外帶點餐
- ✅ 手機號碼作為取餐憑證
- ✅ 可查看訂單狀態
- ✅ 支援提前點餐

## 👤 會員功能

註冊成為會員後，您可以享有更多功能！

### 註冊會員

#### 📝 註冊步驟

1. **進入註冊頁面**
   - 點擊首頁的「註冊」按鈕
   - 或在登入頁面點擊「立即註冊」

2. **填寫註冊資料**

   ```
   ┌────────────────────────────────┐
   │  會員註冊                      │
   │                                │
   │  姓名                          │
   │  ┌──────────────────────────┐  │
   │  │ 王小明                   │  │
   │  └──────────────────────────┘  │
   │                                │
   │  手機號碼                      │
   │  ┌──────────────────────────┐  │
   │  │ +886 912345678           │  │
   │  └──────────────────────────┘  │
   │                                │
   │  Email（可選）                 │
   │  ┌──────────────────────────┐  │
   │  │ wang@example.com         │  │
   │  └──────────────────────────┘  │
   │                                │
   │  密碼                          │
   │  ┌──────────────────────────┐  │
   │  │ ••••••••                 │  │
   │  └──────────────────────────┘  │
   │                                │
   │  確認密碼                      │
   │  ┌──────────────────────────┐  │
   │  │ ••••••••                 │  │
   │  └──────────────────────────┘  │
   │                                │
   │  [註冊]                        │
   └────────────────────────────────┘
   ```

3. **完成註冊**
   - 點擊「註冊」按鈕
   - 系統會自動登入您的帳號

#### ⚠️ 注意事項

- 手機號碼必須填寫，作為登入帳號
- 密碼至少 8 個字元
- Email 為選填，可用於密碼重設

#### ➕ 基本步驟

1. **點擊菜品卡片**
   - 顯示菜品詳細資訊

2. **查看菜品詳情**

   ```
   ┌────────────────────────────────┐
   │  牛肉麵                        │
   │  ──────────────────────        │
   │                                │
   │  [菜品大圖]                    │

   │  🎛️ 客製化選項：               │
   │  • 辣度：□ 不辣 □ 小辣 ☑ 中辣 │
   │  • 麵條：☑ 粗麵 □ 細麵 □ 冬粉 │
   │  • 加蛋：□ 不加 ☑ 加蛋 (+10元)│
   │                                │
   │  🔢 數量： - [1] +             │
   │                                │
   │  💬 備註：                     │
   │  ┌──────────────────────────┐  │
   │  │ 不要香菜                 │  │
   ```

   - 辣度、甜度
   - 配料選擇

   - 點擊 - 或 + 按鈕
   - 或直接輸入數量

   - 例如：「不要香菜」、「少冰」、「另外裝」

- 可以一次加入多個數量
- 備註欄位可以告訴廚房特殊需求
- 如果選項有加價，會自動計算總金額

### 修改購物車

#### ✏️ 可用操作

1. **調整數量**
   - 點擊 - 減少數量
   - 點擊 + 增加數量

2. **刪除項目**
   - 點擊垃圾桶圖示
   - 確認刪除

3. **繼續點餐**
   - 點擊「繼續點餐」返回菜單
   - 購物車內容會保留

4. **清空購物車**
   - 點擊「清空購物車」
   - 所有項目會被移除

### 送出訂單

#### 📤 送出步驟

1. **確認訂單內容**
   - 檢查所有品項和數量
   - 確認總金額正確

2. **填寫訂單備註**（選填）
   - 例如：「請盡快出餐」、「分開裝」

3. **點擊「送出訂單」**
   - 系統會確認訂單資訊

4. **確認送出**

   ```
   ┌────────────────────────────────┐
   │  ⚠️ 確認送出訂單？             │
   │                                │
   │  訂單一旦送出就無法修改，      │
   │  請確認訂單內容無誤。          │
   │                                │
   │  總金額: NT$ 341               │
   │                                │
   │  [取消]  [確認送出]            │
   └────────────────────────────────┘
   ```

5. **訂單送出成功**
   - 顯示訂單編號
   - 自動跳轉到訂單追蹤頁面

#### ⚠️ 重要提醒

- ⚠️ 訂單送出後無法修改或取消
- ⚠️ 請確保訂單內容正確再送出
- ⚠️ 如有錯誤，請聯繫服務人員

## 🪑 候位

店家有開放候位時，可以先取號，不必在門口排隊。候位網址通常由店家的 QR 或連結提供（`/r/店家代碼/wait-list`）。

### 取號

1. 開啟候位頁，標題為「加入候位」。
2. 填寫**姓名**、**手機號碼**、**用餐人數**（1～8 位），有特殊需求可填**備註**。
3. 手機須是 **09 開頭的台灣手機號碼**（例如 0912 345 678，空格與「-」會自動忽略），否則會提示「請輸入 09 開頭的台灣手機號碼。」
4. 按「加入排隊」。成功後會直接進入「我的候位號碼」頁。
5. 頁面下方會顯示「目前候位」組數與「預估等待」分鐘數，可在取號前參考。

> 推播通知目前尚未開放，取號後請留在本頁，或之後用手機號碼查詢。

### 查看我的號碼

「我的候位號碼」頁會顯示**候位號碼**、**目前狀態**、**前方組數**、**預估等待**，以及姓名與人數。

- 頁面會自動更新，直到號碼進入最終狀態；若瀏覽器分頁在背景，更新會暫停，切回來即可。
- 狀態有：候位中、已叫號、已確認抵達、已入座、已取消、已逾時、未到。
- 請不要把這個頁面的網址公開轉貼，它就是你這張號碼的憑證。

### 叫號後與可用的按鈕

| 按鈕 | 何時出現 | 作用 |
| --- | --- | --- |
| 確認已抵達 | 狀態為「已叫號」時 | 告知店家你已到店 |
| 先點餐 | 號碼尚未結束時 | 前往該店菜單先點餐 |
| 取消候位 | 號碼尚未結束時 | 放棄這個號碼 |
| 重新取號 | 號碼已結束（取消、逾時等）後 | 回到取號頁重新登記 |
| 回首頁 | 號碼已結束後 | 回到 MakanMakan 首頁 |

### 忘了號碼或換了手機

- 在取號頁按「**用手機查詢號碼**」，輸入原本的手機號碼，可找回目前有效的號碼；查無時會顯示「查無此手機號碼的有效候位。」
- 想看過去的紀錄，按「**查看歷史紀錄**」（`/r/店家代碼/wait-list/history`），輸入手機號碼後按「載入歷史紀錄」，點「查看號碼」可回到那一張。
- 若系統要求驗證手機，會帶你到登入頁以**簡訊驗證碼**驗證，完成後自動回到歷史頁，這是正常流程。

### 候位常見問題

- **取不到號**：店家可能尚未開放候位，或暫時無法加入，請稍後再試或洽現場人員。
- **預估等待不動**：這只是估計值，請以店家叫號為準。
- **號碼顯示已逾時**：號碼已失效，請按「重新取號」。

## 🛍️ 市集多攤位結帳

在「市集」頁面（`/markets`）選到一個市集後，可以把**不同攤位**的餐點放進同一個市場購物籃，一次送出，之後在同一頁追蹤。

> 此功能需店家與平台開放。未開放時，送出按鈕會呈灰色並顯示「尚未開放」，提示「多攤位結帳尚未開放，可先到各攤位分別下單。」這時請改到各攤位分別下單。

### 送出多攤位訂單

1. 進入市集頁，在各攤位把餐點加入「市場購物籃」，購物籃會顯示「N 個攤位，N 項」。
2. 需要**至少 2 個攤位**才能多攤位結帳，不足時會顯示提示。
3. 若有攤位今天沒有營業，系統會把它從購物籃移除並提醒你，請確認後再送出。
4. 輸入**手機末三碼**，按「送出」。這三碼是日後找回訂單的憑證，請記住。
5. 成功會顯示「已送出 N 筆攤位訂單」，並進入市場訂單追蹤頁（`/markets/市集代碼/checkout/結帳編號`）。

### 市場訂單追蹤頁

頁面上方是市集名稱與整體狀態（**處理中**或**已送出**）、攤位數、送出時間，以及：

- **小計**、**卷折抵**（有使用優惠卷時）、**應付**金額。
- **攤位訂單**清單：每個攤位各有一筆訂單與訂單號，可按「查看攤位訂單」進入該攤的訂單追蹤。
- 各攤位的製作進度（待確認、已確認、製作中、可取餐、已完成……）仍由該店負責，**請以店家現場叫號或通知為準**，此頁只保留市場層級的摘要。

### 使用優惠卷與聯合付款

1. 若頁面顯示「輸入卷碼」，輸入卷碼按「套用」；要取消按「移除」。
2. 卷無法使用時會說明原因：找不到、不適用此市場結帳、已過期、已用完、未達最低消費。已付款的訂單不能再更換卷。
3. 按「**聯合付款**」一次付清所有攤位。付款中會顯示「付款處理中」，並依付款方式帶你到付款頁，**付完請回到這一頁**追蹤。
4. 頁面會顯示「已完成 X / Y 筆攤位付款」。部分攤位付款完成時，整體為「部分付款完成」，可按「重試未完成付款」。付款失敗時按「重新付款」，並確認付款方式。
5. 若顯示「市場聯合付款尚未開放，請直接向各攤位結帳」，請到各攤位現場結帳。

### 無法開啟攤位訂單怎麼辦

若出現「無法開啟攤位訂單，請從最近市場訂單重新進入」，代表這台裝置上找不到那張子單的存取憑證。回到市場訂單追蹤頁重新進入，或把訂單號與手機末三碼告知店員協助確認，不要自行重複送單。

## ❓ 常見問題 (FAQ)

### 🤔 使用相關

**Q1: 需要下載 APP 嗎？**
A: 不需要！只要用手機瀏覽器掃描 QR Code 即可使用。

**Q2: 一定要註冊會員才能點餐嗎？**
A: 不一定。桌台點餐模式可以不註冊直接點餐。但註冊會員後可以查看訂單歷史。

**Q3: 手機驗證碼收不到怎麼辦？**
A: 請檢查：

- 手機號碼是否正確
- 是否被手機封鎖為垃圾簡訊
- 網路連線是否正常
- 聯絡餐廳服務人員協助

**Q4: 可以同時點兩桌的餐嗎？**
A: 不建議。每個桌台的 QR Code 是獨立的，建議分別掃描點餐。

**Q5: 訂單送出後可以取消嗎？**
A: 訂單送出後無法在系統中取消，請立即聯絡服務人員處理。

---

### 🛒 購物車相關

**Q6: 購物車有時間限制嗎？**
A: 購物車內容會保存 24 小時，超過時間可能被清空。

**Q7: 為什麼有些菜品無法加入購物車？**
A: 可能原因：

- 該菜品暫時售完
- 不在供應時段（例如只提供午餐）
- 系統維護中

**Q8: 可以一次點多個餐廳的餐嗎？**
A: 不可以。每個購物車只能包含一家餐廳的菜品。

---

### 💰 付款相關

**Q9: 如何付款？**
A: 目前採用現場付款方式，用餐後至櫃檯結帳。

**Q10: 可以使用信用卡或行動支付嗎？**
A: 依各餐廳規定，請向服務人員確認可用的付款方式。

---

### 📱 技術相關

**Q11: 為什麼網頁載入很慢？**
A: 可能原因：

- 網路訊號不佳
- 手機記憶體不足
- 嘗試重新整理頁面

**Q12: 離線也能使用嗎？**
A: 可以瀏覽已載入的菜單，但送出訂單需要網路連線。

**Q13: 支援哪些瀏覽器？**
A: 建議使用：

- Safari（iOS）
- Chrome（Android）
- 其他現代瀏覽器

**Q14: 可以在電腦上使用嗎？**
A: 可以，但系統是為手機優化的，建議使用手機獲得最佳體驗。

---

### 🔐 帳號相關

**Q15: 忘記密碼怎麼辦？**
A: 點擊登入頁面的「忘記密碼」，使用註冊的 Email 重設密碼。

**Q16: 可以更改手機號碼嗎？**
A: 目前不支援更改手機號碼，請聯絡客服協助。

**Q17: 可以刪除帳號嗎？**
A: 請聯絡客服申請刪除帳號。
