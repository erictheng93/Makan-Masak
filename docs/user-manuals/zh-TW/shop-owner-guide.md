### 用 Google／LINE 登入（擁有多家店時）

管理後台可以用 Google 或 LINE 登入，不必每次輸入密碼。系統**不會**用 Email
自動找出你名下有哪些店，所以每家店都要各自連結一次：

1. 用 **A 店的帳號密碼**登入管理後台。
2. 到「設定 > 安全 > 登入方式」，按「連結 Google」或「連結 LINE」，完成授權。
3. 登出，改用 **B 店的帳號密碼**登入，重複第 2 步，連結**同一個** Google／LINE。
4. 其他店照做。

完成後，在登入頁按「使用 Google 登入」或「使用 LINE 登入」：

- 只連結過一家店：直接進入那家店，不會出現選店畫面。
- 連結過兩家以上：會出現「選擇要進入的店」，點選店名即可進入。

注意：

- 選店畫面只列出**已在該店連結過**的店。看不到某家店，代表那家店還沒連結，
  請用該店帳號密碼登入後補做第 2 步。
- 解除連結是一家一家分開的：在 A 店解除，不影響 B 店。
- 若登入時出現「這個帳號尚未連結任何店主帳號」，表示這個 Google／LINE
  還沒有在任何一家店連結過。

## ⚙️ 餐廳基本設定

### 餐廳資訊管理

前往：**儀表板 → 餐廳設定 → 基本資訊**

#### 必填資訊

| 欄位     | 說明                   | 範例                      |
| -------- | ---------------------- | ------------------------- |
| 餐廳名稱 | 顯示在顧客端的店名     | 美味海鮮餐廳              |
| 餐廳地址 | 完整地址（含郵遞區號） | 台北市信義區信義路五段7號 |
| 聯絡電話 | 客服或訂位專線         | 02-1234-5678              |
| 營業時間 | 每日營業時段           | 11:00-14:00, 17:00-21:00  |
| 餐廳描述 | 簡介、特色說明         | 提供新鮮海產與傳統料理    |

#### 營業時間設定

```

│                                         │
```

### 餐廳圖片上傳

支援格式：JPG、PNG、WebP
建議尺寸：1920x1080 像素
檔案大小：最大 5MB

**上傳步驟**：

1. 點擊「上傳圖片」按鈕
2. 選擇餐廳外觀或特色菜品圖片
3. 系統自動壓縮並產生多種尺寸
4. 確認預覽後儲存

### 批次管理菜品

#### 批次更新價格

前往：**菜單管理 → 批次操作 → 價格調整**

使用場景：

- 季節性調價
- 成本上漲調整
- 促銷活動設定

**操作步驟**：

1. 選取要調整的菜品（可多選）
2. 設定調整方式：
   - 固定金額調整（如：+$10）
   - 百分比調整（如：+5%）
3. 預覽調整結果
4. 確認後套用

#### 批次啟用/停用

快速操作：

- ✅ 一鍵啟用選定菜品
- ⏸️ 一鍵暫停選定菜品
- ❌ 一鍵停用選定菜品

```
┌─────────────────────────────────────┐
```

#### Q1: 找不到「AI 洞察」菜單項？

**原因分析**：

- 使用的帳號角色不正確（只有 Admin 和店主可訪問）
- 瀏覽器快取未更新

**解決方法**：

```
步驟 1: 確認帳號角色

   按 Ctrl + Shift + R 強制刷新頁面

   位置：在「數據分析」和「POS系統」之間

   http://your-domain.com/dashboard/ai-analytics/insights
```

#### Q2: API Key 配置失敗怎麼辦？

**常見錯誤訊息**：

- ❌ "API Key 無效"
- ❌ "連接超時"
- ❌ "權限不足"

**解決步驟**：

| 錯誤類型     | 檢查項目         | 解決方案                     |
| ------------ | ---------------- | ---------------------------- |
| API Key 無效 | Key 是否正確複製 | 重新複製完整 Key（不含空格） |
| API Key 無效 | Key 是否已啟用   | 前往 Provider 官網啟用 API   |
| 連接超時     | 網路是否正常     | 檢查防火牆設定               |
| 連接超時     | API 服務狀態     | 查看 Provider 服務狀態頁     |
| 權限不足     | API Key 權限     | 確認 Key 有 API 調用權限     |
| 權限不足     | 額度是否耗盡     | 檢查帳單和使用額度           |

**API Key 取得方式**：

**Anthropic Claude**：

1. 前往 https://console.anthropic.com/
2. 註冊並驗證帳號
3. 前往 API Keys 頁面
4. 點擊 "Create Key"
5. 複製金鑰（格式：sk-ant-xxx...）

**OpenAI GPT**：

1. 前往 https://platform.openai.com/
2. 登入帳號
3. 前往 API Keys 設定
4. 點擊 "Create new secret key"
5. 複製金鑰（格式：sk-xxx...）

#### Q3: AI 報告生成失敗？

**錯誤訊息**：「AI 分析生成失敗，請稍後再試」

**可能原因與解決方案**：

```
【原因 1】數據不足

最低要求：
• 至少 7 天的營運數據
• 至少 20 筆訂單記錄
• 至少 5 個菜品銷售記錄

解決方案：
→ 等待累積更多數據
→ 選擇較長的時間範圍（30天 或 90天）

【原因 2】API 額度不足

症狀：
• 測試連接成功
• 但生成報告失敗

解決方案：
→ 登入 AI Provider 官網
→ 檢查帳單和剩餘額度
→ 儲值或升級方案

【原因 3】網路連接問題

症狀：
• 頁面載入緩慢
• 請求超時

解決方案：
→ 檢查網路連接
→ 嘗試使用其他網路
→ 聯絡 IT 支援檢查防火牆

【原因 4】系統暫時性錯誤

解決方案：
→ 等待 5 分鐘後重試
→ 點擊「刷新」按鈕清除快取
→ 如持續失敗，聯絡技術支援
```
