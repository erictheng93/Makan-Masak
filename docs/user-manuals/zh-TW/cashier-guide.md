- [ ] 登入收銀系統

## 🧾 訂單結帳流程

### 標準結帳步驟

#### 步驟 1：查詢訂單

**方式一：桌號查詢**

```
1. 點選「快速搜尋」
2. 輸入桌號（如：A1、B3）
3. 系統顯示該桌台所有未結帳訂單
4. 確認是顧客的訂單
```

**方式二：訂單號查詢**

```
1. 向顧客索取訂單號
2. 輸入訂單號碼
3. 系統顯示訂單詳情
4. 確認訂單內容
```

**方式三：手機號查詢**

```
1. 詢問顧客是否為會員
2. 輸入顧客手機號碼
3. 系統列出該會員的未結帳訂單
4. 請顧客確認要結帳的訂單
```

#### 步驟 4：處理付款

**現金付款流程：**

```
1️⃣ 告知顧客總金額
   「您好，總共是 561 元」

2️⃣ 收取現金
   顧客支付：NT$ 1,000

3️⃣ 輸入實收金額
   系統自動計算找零：NT$ 439

4️⃣ 確認金額無誤後點選「完成付款」

5️⃣ 準備找零
   - 400 元：4張 100 元
   -  30 元：1個 10 元、2個 10 元
   -   9 元：1個 5 元、4個 1 元

6️⃣ 覆誦找零金額
   「找您 439 元，謝謝」
```

**信用卡付款流程：**

```
1️⃣ 選擇「信用卡」付款
2️⃣ 輸入付款金額：NT$ 561
3️⃣ 插入/感應信用卡
4️⃣ 等待授權中...
5️⃣ 請顧客輸入密碼/簽名
6️⃣ 交易成功 ✅
7️⃣ 列印簽單（需簽名）
8️⃣ 請顧客簽名確認
9️⃣ 將簽單存檔
```

**行動支付流程：**

```
1️⃣ 選擇「行動支付」
2️⃣ 選擇支付平台
   • LINE Pay
   • 街口支付
   • Apple Pay
   • Google Pay

3️⃣ 顯示付款 QR Code
4️⃣ 顧客掃描 QR Code
5️⃣ 等待支付確認...
6️⃣ 支付成功 ✅
7️⃣ 自動完成結帳
```

## 💳 付款方式處理

### 現金付款

#### 收取現金注意事項

```
┌─────────────────────────────────────────────┐
│ 現金收取標準流程                            │
├─────────────────────────────────────────────┤
│                                             │
│  1️⃣ 明確告知金額                           │
│     「總共是 561 元」                       │
│                                             │
│  2️⃣ 確認收到的紙鈔面額                     │
│     「收您 1000 元」                        │
│                                             │
│  3️⃣ 將紙鈔放在收銀機上方（避免爭議）       │
│                                             │
│  4️⃣ 在系統中輸入實收金額                   │
│                                             │
│  5️⃣ 確認找零金額正確                       │
│     系統顯示：找零 439 元                  │
│                                             │
│  6️⃣ 點鈔找零                               │
│     - 先給大鈔（百元）                     │
│     - 再給零錢（十元、一元）               │
│                                             │
│  7️⃣ 覆誦找零金額                           │
│     「找您 439 元」                         │
│                                             │
│  8️⃣ 將收到的紙鈔放入錢箱                   │
│                                             │
└─────────────────────────────────────────────┘
```

#### 真偽鈔辨識

**檢查重點：**

| 紙鈔          | 檢查方式                       |
| ------------- | ------------------------------ |
| 💵 **1000元** | 光影變化箔膜、凹版印紋、安全線 |
| 💵 **500元**  | 隱藏字「500」、梅花水印        |
| 💵 **100元**  | 光影變化油墨、盲人點字         |

**可疑紙鈔處理：**

```
1. 不要直接指控顧客
2. 禮貌地說：「抱歉，這張鈔票好像有點問題，可以換一張嗎？」
3. 如果顧客堅持，請主管協助處理
4. 保留可疑鈔票，交由主管或警方處理
```

#### 交易失敗處理

| 錯誤訊息            | 原因          | 處理方式                   |
| ------------------- | ------------- | -------------------------- |
| ❌ **餘額不足**     | 信用額度已滿  | 請顧客改用其他卡或付款方式 |
| ❌ **卡片過期**     | 信用卡已過期  | 請使用有效期限內的信用卡   |
| ❌ **交易拒絕**     | 銀行拒絕授權  | 建議聯絡發卡銀行或改用他法 |
| ❌ **連線失敗**     | 網路問題      | 重新刷卡或改用現金         |
| ❌ **卡片讀取失敗** | 磁條/晶片損壞 | 清潔卡片後重試或換卡       |

### 混合付款

當顧客使用多種付款方式時：

```
範例：總金額 NT$ 1,200

顧客想使用：
  • 禮券：NT$ 500
  • 信用卡：剩餘金額

操作步驟：
1️⃣ 選擇「混合付款」
2️⃣ 先處理禮券
   - 選擇「禮券」
   - 輸入或掃描禮券號碼
   - 系統驗證並扣除 NT$ 500

3️⃣ 系統顯示剩餘金額：NT$ 700
4️⃣ 處理剩餘金額
   - 選擇「信用卡」
   - 刷卡支付 NT$ 700

5️⃣ 完成交易 ✅
```

## ⚠️ 異常處理

### 常見異常情況

#### 1. 系統當機

```
現象：收銀系統無法啟動或突然關閉

處理步驟：
1️⃣ 保持冷靜，向顧客致歉
2️⃣ 告知顧客：「系統暫時有點問題，請稍等」
3️⃣ 立即通知資訊人員或主管
4️⃣ 嘗試重新啟動系統
5️⃣ 如無法立即修復：
   • 暫時使用手寫單據
   • 記錄交易資訊
   • 系統恢復後補登
6️⃣ 保持與顧客溝通，減少等待焦慮
```

---

#### 2. 收據機故障

```
現象：無法列印收據、卡紙、印刷不清

處理步驟：
1️⃣ 判斷故障原因
   • 缺紙？→ 更換收據紙捲
   • 卡紙？→ 打開機器清除
   • 印刷不清？→ 清潔印字頭

2️⃣ 如無法立即修復
   • 手寫臨時收據
   • 註記訂單號碼
   • 告知顧客稍後補印

3️⃣ 通知維修人員
4️⃣ 填寫設備維修單
```

**更換收據紙步驟：**

```
1. 打開收據機上蓋
2. 取出舊紙捲（若有剩餘）
3. 放入新紙捲
4. 將紙頭拉出約10公分
5. 關閉上蓋
6. 按「進紙」鍵測試
```

---

#### 3. 刷卡機故障

```
現象：無法讀卡、連線失敗、交易異常

處理步驟：
1️⃣ 基本檢查
   • 確認電源線已插好
   • 檢查網路連線
   • 嘗試重新啟動

2️⃣ 如無法立即修復
   • 禮貌告知顧客：「刷卡機暫時無法使用」
   • 建議改用其他付款方式：
     ✓ 現金
     ✓ 行動支付
     ✓ 稍後再結帳

3️⃣ 通知主管和銀行客服
4️⃣ 填寫設備異常報告
```

---

#### 4. 網路中斷

```
現象：無法連線、交易失敗、資料無法上傳

處理步驟：
1️⃣ 確認是否為全面性斷線
   • 檢查其他設備是否正常
   • 詢問其他同事情況

2️⃣ 切換到離線模式（如有）
   • 使用本地端功能
   • 記錄交易資訊
   • 待網路恢復後同步

3️⃣ 通知網路管理人員
4️⃣ 如需緊急處理：
   • 使用手機熱點
   • 手寫記錄交易

5️⃣ 網路恢復後
   • 同步離線交易資料
   • 確認資料完整性
```

---

#### 5. 找零金不足

```
現象：錢箱中某種面額不夠找零

處理步驟：
1️⃣ 禮貌告知顧客：「抱歉，目前缺少零錢」
2️⃣ 提供替代方案：
   • 「可以找您其他面額嗎？」
   • 「可以改用刷卡或行動支付嗎？」
   • 「我去跟其他收銀台調零錢，請稍等」

3️⃣ 快速向其他收銀台借調
4️⃣ 完成找零
5️⃣ 向顧客致歉並感謝等待
6️⃣ 記錄零錢需求，通知主管補充
```

---

#### 6. 收到疑似假鈔

```
處理原則：不動聲色、禮貌處理、保護雙方

處理步驟：
1️⃣ 不要直接指控顧客
2️⃣ 使用檢測設備確認
3️⃣ 如確實可疑，禮貌地說：
   「抱歉，這張鈔票好像有點問題，
    我需要請主管確認一下，
    或者您可以換一張嗎？」

4️⃣ 立即通知主管
5️⃣ 主管判斷後決定：
   • 退還給顧客，請其換鈔
   • 收下並報警處理

6️⃣ 全程保持禮貌，避免衝突
7️⃣ 事後填寫異常報告
```

---

#### 7. 顧客對金額有異議

```
現象：顧客認為金額算錯、多收錢

處理步驟：
1️⃣ 保持冷靜和禮貌
2️⃣ 說：「不好意思，我再確認一次」
3️⃣ 調出訂單明細
4️⃣ 逐項向顧客說明：
   「您點的是：
    • OO麵 NT$ 150
    • OO飯 NT$ 120
    • 飲料 NT$  50
    總共是 NT$ 320」

5️⃣ 如確實算錯：
   • 誠懇道歉
   • 立即更正
   • 補足差額或退還多收款項

6️⃣ 如金額正確：
   • 耐心解釋
   • 展示價目表
   • 必要時請主管協助

7️⃣ 填寫客訴記錄
```

---

#### 8. 系統金額顯示異常

```
現象：系統顯示的金額明顯不合理

處理步驟：
```

### 詐騙防範

**常見詐騙手法：**

```
❌ 詐騙類型 1：假冒客服
   「我是總公司客服，系統出問題，
    需要你協助測試退款功能...」

   → 絕不配合任何電話要求的操作
   → 掛斷電話，聯絡直屬主管確認


❌ 詐騙類型 2：調包詐騙
   顧客付款後說：「剛剛那張我要換開」
   趁機調包或多拿錢

   → 收到的鈔票立即放入錢箱
   → 不接受換鈔要求


❌ 詐騙類型 3：金額混淆
   「我剛剛給你 1000，你找我的不對」
   實際上給的是 500

   → 收大鈔時先放收銀機上方
   → 大聲覆誦「收您 1000 元」
   → 找零後再將鈔票放入錢箱


❌ 詐騙類型 4：偽造支付畫面
   手機顯示已付款，實際未完成

   → 必須確認系統收到款項
   → 不能只看顧客手機畫面
   → 等待系統確認後才完成結帳
```
