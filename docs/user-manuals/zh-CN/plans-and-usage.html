方案、试用期与用量

给店主的说明：怎么查看当前的方案和用量，以及自己更换方案

简体中文 繁體中文 English 日本語 Tiếng Việt Bahasa Indonesia

先看重点

  • MakanMasak 有四种方案：试用版、标准版、专业版、企业版。每家新店都从试用版开始，试用 180 天，所有功能都能用。
  • 试用期结束，不会被停用。系统只会提醒你选择方案，店里照常营业。
  • 每个方案都有订单数、打印数等用量上限。用到 80% 会提醒；用满后，新的订单和小票打印会暂停，直到下一个计算期，或者你升级方案为止。
  • 方案由店主自己在后台的 订阅与用量 更换，不需要在线支付，也不用联系客服。
  • 升级立即生效，用量从 0 重新计算；降级在本期结束时才生效，生效前可以取消。
  • 本页不介绍任何费用。如果以后有收费，平台会另行公告。

试用期

  • 每家新店都从试用版开始，180 天，所有功能都能用。
  • 在 订阅与用量 页面，当前方案下方会写着“试用期剩余 N 天”。
  • 试用版的订单和打印上限是整个试用期的总数（各 3,000），不是每个月重新计算。

试用期结束后

什么都不会被关掉 所有功能照常使用，店里不需要停业。后台只会出现提醒：顶部有一条横幅“试用期已结束。所有功能仍可继续使用，但请选择方案以支持 MakanMasak。”，每次登录还会弹出一次“试用期已结束”窗口，你可以点“继续使用”关掉，或点“选择方案”直接去挑方案。
  • 试用期结束后、在你选择方案之前，用量上限仍是试用版的数字，但改为按日历月计算（每月重新归零）。
  • 离开试用版（选择标准版、专业版或企业版）立即生效。
  • 离开试用版之后，就不能再回到试用版。试用版只提供给新开的店。

用量怎么算、去哪里看

系统会统计三种有上限的用量：

  • 创建订单：每创建一笔新订单算 1。包括顾客在线上或扫二维码下的单、团体订单、跨店铺的合并结账，以及员工代客创建的订单。
  • 打印任务：每打印一次小票算 1。
  • AI 请求：使用 AI 分析功能时计算。

“一期”是多久

你的情况用量怎么算
试用期内整个试用期（180 天）合计，不重新计算
试用期结束、尚未选方案每个日历月，月初归零
标准版、专业版、企业版从你选择该方案的那一刻起，每 30 天为一期，期满自动进入下一期并从 0 开始

日历月的起止以世界标准时间（UTC）为准，与当地时间有时差，例如中国是每月 1 日早上 8 点归零。

在哪里看

  1. 登录后台，从左侧菜单选 订阅与用量。
  2. “本期用量”区块会列出每一项已使用的数量、上限，以及这一期的起止日期。
  3. 进度条会随用量变色：未到 80% 是蓝色，达到 80% 是橙色，用满是红色。

快用完时的提醒

用到上限的 80%，后台顶部会出现橙色横幅，例如“本期订单已使用 85%（2,550/3,000）”，旁边有 查看方案 按钮。你可以点右边的 ✕ 先关掉（本次登录期间不再显示）。这个提醒只有店主看得到。

用量用满时会怎样

用量达到上限后，到下一个计算期开始或你升级方案之前：

  • 新订单会被拒绝：顾客在线上或扫二维码无法下单，员工也无法代客创建新订单、开团体订单。已经成立的订单不受影响，照常制作、出餐、结账。
  • 无法打印小票。
  • 其他功能不受影响。

此时后台顶部会出现红色横幅，不能关闭：“已达订单上限，顾客目前无法下单”或“已达打印上限，目前无法打印小票和单据”。系统也会给你发一封通知邮件（见“通知邮件”）。

最快恢复的方法：升级方案 升级立即生效，而且用量会从 0 重新计算，所以刚刚用满的店，升级后马上就能再接单。做法见下一节。

顾客那边看到的只是“现在无法下单”，建议你在用量快用完时（看到橙色横幅）就先处理，不要等顾客来问你才发现。

升级方案（立即生效）

升级是指从低档换到高档：标准版 → 专业版 → 企业版。从试用版换到任何其他方案，也立即生效；换到功能比试用版少的方案（例如标准版）时，卡片上的按钮写的是 立即更改，确认窗口的按钮是 确认更改。

  1. 登录后台，从左侧菜单选 订阅与用量。（用量提醒横幅上的 查看方案、试用期结束横幅上的 选择方案，都会直接带你到下一步。）
  2. 往下找到“选择方案”区块。四种方案各一张卡片，写有每期上限和包含的功能；当前的方案标有“当前方案”。
  3. 在想要的方案卡片上点 立即升级。
  4. 屏幕上会弹出确认窗口“更改为○○版”，写着“将立即生效。”和“本期用量将从 0 重新计算。”，并列出“新增的功能”。确认无误后点 确认升级。
  5. 看到“方案已更改为○○版”就完成了。顶部的橙色或红色横幅很快会消失。
升级之后 新功能马上出现；用量归零，新的 30 天计算期从这一刻开始；如果你之前预约了降级，也会一并取消。全程不需要付款，也不用联系任何人。

降级方案与取消降级

降级是指从高档换到低档，例如专业版 → 标准版。降级不会马上生效，而是等本期结束才换，在那之前你仍然可以使用现有方案的全部功能。

预约降级

  1. 在 订阅与用量 的“选择方案”区块，找到想换到的较低方案。
  2. 点卡片上的 预约降级，○月○日 生效（日期就是本期结束日）。
  3. 确认窗口会写“将于本期结束（日期）生效，在此之前仍可使用当前方案的功能。”和“新方案的用量自生效日起重新计算。”，并列出“将失去的功能”和“更改后的影响”，例如“3 笔未来的预订会保留，顾客仍可查看或取消，但后台无法再管理，也不能接受新预订；升级后会恢复”。请逐项看过。
  4. 确定要换就点 确认预约降级，会看到“已预约降级为○○版”。

预约之后，页面顶部会出现橙色提示“已预约于 ○月○日 降级为 ○○版”，方案卡片上也会标示“已预约于 ○月○日 生效”。如果你再预约另一个降级，会取代原来那一笔。

生效时间

本期结束时，系统会自动换成新方案，并开始新的一期、用量从 0 算起。系统每天处理一次已预约的变更，所以实际切换的时间可能比画面上的日期晚几个小时；在那之前你仍在原来的方案。

取消已预约的降级

  1. 在 订阅与用量 页面顶部的橙色提示上，点 取消降级（预约要换到的那张方案卡片上，按钮也会变成同一个）。
  2. 在“取消已预约的降级？”窗口确认；你会继续使用当前的方案。看到“已取消降级”就完成了。

生效之后就不能取消了；想换回去，要按“升级”的步骤再升级一次。

失去某个功能之后会怎样

降级（或离开试用版换到功能较少的方案）后，方案里没有的功能会这样处理：

  • 后台的对应页面会关闭。例如降到标准版后，POS 收银、厨房显示、优惠券、订位候位、数据分析的页面都不能再进入。
  • 你的数据不会被删除。预订、服务预约、班表、食材、优惠券等记录都还在，只是暂时看不到；以后再升级回有这些功能的方案，一切会恢复。
  • 顾客端：
    • 顾客不能再新增线上预订、服务预约，也不能加入候位；候位的实时排队情况也不再提供。
    • 顾客仍然可以查看并取消他们已有的预订、服务预约和候位。
    • 店铺自己的优惠券不能再使用；平台自身的优惠活动不受影响。
  • 外送整合：外卖平台传来的订单仍会继续进来，你也仍可以在后台把整合断开连接；但无法再设置或同步整合，相关的设置和列表页面会关闭。
  • 人事管理：已排定的班表、待审核的请假申请会保留，但排班和请假页面会关闭。食材库存：订单仍会自动扣库存，但你无法再查看或管理，升级后恢复。

降级前，确认窗口会根据你店里的实际数据告诉你受影响的数量，请在点“确认预约降级”前看清楚。

特殊情况

还有没结束的收银班次

从有 POS 的方案换到没有 POS 的方案（专业版或企业版 → 标准版；或试用版 → 标准版），要先把收银班次结束。

  • 立即生效的情况（试用版换到标准版，按钮为“立即更改”）：班次还没结束时，系统不会让你换，会提示“仍有未结束的收银班次，请先到 POS 结束班次再降级。”确认窗口上有 前往 POS 结束班次 可以直接过去。
  • 预约的降级：到了生效日如果班次还开着，降级会等到班次结束后才生效。页面上会显示“已预约降级为○○版，但仍有未结束的收银班次，结束班次后才会生效。”记得尽快结班。
方案显示“无法选择”：这个方案在你的地区没有提供

有些方案在部分国家或地区尚未开放，卡片上会写“此方案在您所在的地区暂未提供。”，按钮不能点。请改选其他方案。

试用版显示“无法选择”

离开试用版之后就不能回去，卡片上会写“试用版仅限新店铺，无法再回到试用版。”

“方案刚刚已被其他人更改”

如果有另一位店主账号或平台人员在你操作的同时也改了方案，你会看到“方案刚刚已被其他人更改，已为您刷新页面，请确认后再试。”你的操作没有被执行，页面已刷新成最新状态，确认后重新操作一次即可。

“您已经在使用这个方案”或“当前没有已预约的降级”

说明画面上的信息已经过期（例如在另一个标签页已经操作过），系统会自动刷新页面，不需要再做什么。

“订阅当前已停用，无法更改方案”

订阅被平台停用时，不能自己换方案，请到“意见反馈”页面提交问题，由平台人员协助。

你会收到的通知邮件

以下情况，系统会发邮件到店铺登记的联系邮箱（请确认它是你会查看的邮箱）：

  • 方案已更改：升级立即生效，或已预约的降级到期生效时。
  • 已预约降级：邮件中会写哪一天生效，以及可以到后台取消。
  • 已取消降级。
  • 用量已达上限：同一项用量在同一期只发一次。

目前所有通知邮件都是以英文发送。

谁可以更改方案

只有店主（以及平台人员）可以看到 订阅与用量 并更改方案。厨师、服务员、收银员等其他员工账号看不到这一页，也不能更改。用量提醒横幅同样只显示给店主。

常见问题

我的试用到期了，店会被停用吗？

不会。试用期结束后所有功能仍可继续使用，后台只会提醒你选择方案。只是用量上限会改为每月重新计算（仍是试用版的数字）。

升级后，原来的用量会归零吗？

会。升级立即生效，新的 30 天计算期从升级那一刻开始，用量从 0 算起，所以因为用量用满而无法接单的店，升级后马上就能再接单。

降级后，数据会丢失吗？

不会。记录都会保留，只是相关的后台页面暂时关闭；以后升级回有该功能的方案，数据就会回来。

为什么顾客说无法下单？

最常见的原因是本期的订单数已达上限。到后台 订阅与用量 看“本期用量”，如果订单已满，顶部会有红色横幅。升级方案即可立刻恢复；不升级的话，要等下一个计算期开始。

可以改回试用版吗？

不行。离开试用版之后就不能再回到试用版，试用版只提供给新开的店。

降级可以马上生效吗？

不行。降级一律在本期结束时生效，生效前可以取消。

更换方案要付费吗？

目前在后台更换方案不需要在线支付。如果以后有任何收费，平台会另行公告。

用量用满了，但我不想升级，怎么办？

可以等下一个计算期开始（试用期结束后是下个月 1 日；付费方案是当前这一期的结束日，日期显示在“本期用量”右上角）。在那之前，新订单和小票打印会暂停。

需要帮助

  • 在 订阅与用量 的“选择方案”区块右上角，有“方案与用量说明”链接，会打开本页。
  • 方案无法更改、订阅被停用，或对方案有任何疑问，请到后台左侧菜单的 意见反馈 页面提交问题，平台人员会在那里处理。（这是店铺向平台反馈问题的地方，不是“顾客评价”。）
