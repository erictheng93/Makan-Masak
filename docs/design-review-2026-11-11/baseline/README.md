# 原始畫面證據

這個資料夾的 PNG 由本機啟動的五個 Vue 應用程式直接擷取，未更改正式程式碼、CSS 或 DOM 樣式。範例身份、餐廳、菜單、購物車、訂單、廚房工單、租戶與申請資料僅存在隔離瀏覽器／攔截的 API 回應中，不代表正式營運資料；未呼叫正式服務或送出真實訂單。

- 顧客與開店申請使用 390 × 844；營運介面使用 1100 × 820。
- PNG 是目前視窗的第一屏，不是整頁長截圖。超出畫面的內容仍由來源程式碼檢視補足。
- 主要頁面載入後，透過原有關閉按鈕收起暫時錯誤通知；未修改畫面樣式。
- 未提供範例回應的 API 由攔截器回傳 503。`error-state` 表示畫面包含既有元件的空白／錯誤／離線狀態，不能當成已驗證的完整正常流程。
- `blocked` 表示目標頁沒有成功呈現；若發生重新導向，圖片是 `actualRoute` 指出的實際目的頁，不是目標原頁。
- `captured` 代表成功擷取原始元件狀態，不代表所有互動、後端流程或資料情境都已驗證。
- `layout` 記錄使用子頁的同一張截圖，明確標註 `inheritedFrom`，以呈現該容器實際套用的結果。
- 遠端圖片與對外連線均封鎖；圖像空缺會顯示原有佔位元件。

路由、來源檔、實際路徑、狀態、未提供的 API、執行期錯誤與圖片對應，見上層 `baseline-manifest.json`。技術掃描原始輸出另存於 `technical-scan.json`；掃描提示需由人工檢視，不等同確認缺陷。
