## 設計方向

保留 `DESIGN.md` 的 Apple-Native Soft Minimalism、Inter／系統備援字體與共用色票。顧客以藍色、餐廳後台以深橘、平台管理以綠色識別；廚房色彩只用於工作狀態。文字與按鈕使用既有深色階，改善白字搭配亮橘或亮綠時的對比。

- 顧客：把進入點餐、餐點選擇、數量與結帳摘要做清楚；固定操作區保留內容避讓，保留團購分帳、市場子訂單與服務預約的不同流程。
- 餐廳：整理篩選、清單、詳情與確認的閱讀順序。收銀、訂閱、員工出勤、排班與請假各自保留正確任務，不套成同一種儀表板。
- 廚房：放大工單內容、時間、備註與操作目標，讓待處理、製作中、完成的位置穩定；狀態切換同步更新數量。
- 平台：先看異常與影響範圍，再看租戶與部署；保留 token 驗證、租戶詳情、市場編輯與政策設定的不同結構。
- 開店申請：保留完整店家、聯絡、位置與市場欄位，分組提升掃讀；申請狀態依情境顯示，不一律畫成已完成。

## 證據與限制

原版包含 122 張本機截圖，以及使用者授權網址的 5 張實際登入畫面，共 127 張。所有 113 個來源頁面都有對應截圖；4 個路由容器明確沿用子頁截圖。`baseline-manifest.json` 記錄路由、來源、尺寸、範例 API、狀態與擷取來源；詳見 `baseline/README.md`。

本機畫面由原始 Vue 元件直接產生，未改寫其樣式。多數本機頁面包含部分 API 不可用、空或錯誤狀態；這些畫面不能視為完整正常流程的驗證。相片與外部資源在原版擷取時封鎖，因此可能顯示既有圖片佔位。原版皆為第一屏，長頁其餘內容由原始模板與樣式審視補足。

已補看 `admin.makanmasak.com` 的 demo 店主、Admin，以及 `kitchen.makanmasak.com` 的 Chef。實際部署版本以英文顯示，可能與工作區版本不同，對照頁會分別標示。只進行登入、切換檢視及讀取；未變更營運資料，密碼未寫入任何交付檔案。

右側使用獨立範例資料。它是依頁面任務製作的視覺與互動提案，尚未逐項重建正式控制項、完整角色權限、所有資料情境或後端流程。預覽的通用空／錯誤／載入切換不代表每頁的正式狀態實作。服務條款與隱私權頁只示意閱讀結構，正式實作須保留原文。
